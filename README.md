# A/B-тест email-рассылки: какое письмо отправлять и кому

**Страница проекта:** https://wickedstacy085.github.io/ab-test-email

Интернет-магазин разослал два варианта письма (мужские и женские товары) и оставил треть клиентов
без письма — 64 000 клиентов, открытый датасет [MineThatData](data/README.md). Вопрос: окупается ли
рассылка, какую версию отправлять и кому.

**Результат.** Мужская версия добавляет $0,77 выручки на клиента за две недели (ДИ 95%: 0,49–1,05;
+118% к контролю), ≈ $77 тыс. на 100 тыс. писем, и работает во всех сегментах. Женская версия слабее
($0,42) и не работает на клиентах, которые покупают только мужские товары. Рекомендация — мужская версия всей базе.

## Что сделано

| Шаг | Метод |
|---|---|
| Проверка рандомизации | SRM, χ²-тест |
| Чувствительность теста | мощность и MDE для долей |
| Эффект на визиты и покупки | z-тест разности долей |
| Эффект на выручку | t-тест Уэлча + бутстрап (выручка почти вся нулевая) |
| Снижение дисперсии | CUPED — и почему здесь он не помогает |
| Множественные сравнения | поправка Холма |
| Сегменты | эффект по истории покупок, каналу, новизне клиента |

## Структура

```
data/            данные и их описание
src/abtest/      функции анализа: data, design, analysis, segments
tests/           pytest: сверка со statsmodels, бутстрап vs t-интервал, CUPED и Холм на синтетике
index.qmd        страница проекта (Quarto); все числа в тексте считаются из кода
```

## Как воспроизвести

```bash
pip install -r requirements.txt
pytest
quarto render      # Quarto ≥ 1.4
```

Сайт собирается и публикуется GitHub Actions при каждом коммите в `main`; если тесты не проходят, публикации нет.
